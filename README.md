# Telegram бот для напоминаний о домашках и мероприятиях

Бот помогает не забывать о важных событиях, отправляя напоминания за неделю, 3 дня и 1 день до даты события.

## Возможности

- ➕ Добавление домашек и мероприятий
- 📋 Просмотр списка домашек и мероприятий
- 🗑 Удаление событий
- ⏰ Автоматические напоминания за 7, 3 и 1 день до события
- 🎯 Полностью кнопочный интерфейс

## Установка

### 1. Установите Python
Убедитесь, что у вас установлен Python 3.8 или выше:
```bash
python --version
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Создайте бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Придумайте имя для бота (например: "Мой напоминатель")
4. Придумайте username для бота (должен заканчиваться на `bot`, например: `my_reminder_bot`)
5. BotFather даст вам токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
6. Скопируйте этот токен

### 4. Настройте токен

Откройте файл `bot.py` и замените строку:
```python
TOKEN = "YOUR_BOT_TOKEN_HERE"
```

На:
```python
TOKEN = "ваш_токен_от_BotFather"
```

## Запуск

```bash
python bot.py
```

После запуска бот будет работать постоянно. Оставьте окно терминала открытым.

## Использование

1. Найдите вашего бота в Telegram по username
2. Отправьте команду `/start`
3. Используйте кнопки для управления:
   - **➕ Добавить домашку** — добавить новое домашнее задание
   - **➕ Добавить мероприятие** — добавить новое мероприятие
   - **📋 Мои домашки** — посмотреть все домашки
   - **📅 Мои мероприятия** — посмотреть все мероприятия
   - **🗑 Удалить событие** — удалить домашку или мероприятие
   - **📊 Все события** — посмотреть все домашки и мероприятия вместе

### Добавление события

1. Нажмите кнопку "➕ Добавить домашку" или "➕ Добавить мероприятие"
2. Введите название (например: "Контрольная по математике")
3. Введите описание или отправьте `-` чтобы пропустить
4. Введите дату в формате `ДД.ММ.ГГГГ` (например: `15.12.2026`)
5. Готово! Бот автоматически создаст напоминания

## Напоминания

Бот автоматически отправит вам напоминания:
- ⏰ За 7 дней до события
- ⏰ За 3 дня до события  
- ⏰ За 1 день до события

Проверка напоминаний происходит каждые 30 минут.

## Файлы проекта

- `bot.py` — основной файл бота
- `database.py` — работа с базой данных
- `requirements.txt` — список зависимостей
- `reminder_bot.db` — база данных (создается автоматически)

## Остановка бота

Нажмите `Ctrl+C` в терминале, где запущен бот.

## Запуск бота в фоне (Linux/Mac)

Если хотите, чтобы бот работал постоянно в фоновом режиме:

```bash
nohup python bot.py > bot.log 2>&1 &
```

Остановить фоновый процесс:
```bash
pkill -f bot.py
```

## Возможные проблемы

### Бот не запускается
- Проверьте, что правильно указали токен в `bot.py`
- Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`

### Напоминания не приходят
- Убедитесь, что бот запущен и работает
- Проверьте, что дата события в будущем
- Напоминания отправляются только если до события больше 1 дня

### Ошибка с датой
- Используйте формат `ДД.ММ.ГГГГ` (например: `25.12.2026`)
- Дата должна быть в будущем

## Разработка

Бот использует:
- **python-telegram-bot** для работы с Telegram API
- **APScheduler** для планирования напоминаний
- **SQLite** для хранения данных

База данных автоматически создается при первом запуске.
